🌟 Project Overview

DataFlow is a Python-based data processing application designed to read raw CSV files, identify missing values, clean datasets, transform information and generate processed output files.

It also includes a modern web dashboard that displays employee records, salary insights and city-wise statistics.

✨ Key Features
Feature	Description
📂 CSV Reading	Reads employee data from CSV files
🧹 Data Cleaning	Handles missing values
🔄 Data Transformation	Converts text values into numerical values
📊 Analytics Dashboard	Displays employee information visually
🔎 Smart Search	Searches employee records
📈 Salary Visualization	Displays salary comparisons
🏙️ City Analytics	Shows employee distribution by city
📝 Logging	Maintains pipeline activity logs
🧪 Unit Testing	Tests important pipeline functions

⚙️ Installation & Setup
1. Clone the repository
bash
git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder
bash
cd Data-Processing-Pipeline

3. Install dependencies
bash
python -m pip install -r requirements.txt

4. Run the processing pipeline
bash
python main.py

5. Launch the dashboard
bash
python app.py

6. Open in your browser

Visit:

http://127.0.0.1:5000
